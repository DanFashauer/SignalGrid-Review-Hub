# Outreach log — the audit trail of every send and reply

One JSON file per active day, named by date (for example `2026-08-25.json`),
in the format defined in `docs/outreach/OPERATING_RULES.md`. Dispositions
only — reply CONTENT never lands here. An unlogged send is a rule violation.
Empty until the first send day; the emptiness of this directory is itself
the honest record that no outreach has gone out yet.
