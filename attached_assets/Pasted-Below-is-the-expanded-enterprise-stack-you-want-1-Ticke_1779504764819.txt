4. Your “Device Leaving Facility” Architecture

Best design:

Device signal sources:
MDM + Wi-Fi + BLE beacon + badge reader + door controller + cellular/eSIM + location
Event logic:
Device not checked out
AND device crosses exit zone
AND device loses facility Wi-Fi
AND no approved user/badge association
THEN trigger incident
Actions:
1. Alert security
2. Create ServiceNow/Jira incident
3. Send PagerDuty/Opsgenie alert
4. Trigger device sound if reachable
5. Put supervised iOS device into Managed Lost Mode
6. Notify building access/security desk
7. Optionally lock app/session or disable account access

For iOS/iPadOS, Apple Managed Lost Mode can locate, lock, or erase supervised devices when stolen or lost.   But the limitation is important: MDM commands require the device to be online. If it is Wi-Fi-only and leaves the building, you may not reach it again until it joins a network.

6. The Real Answer for “Ping the eSIM”

You generally cannot “ping an eSIM” like a normal device unless the carrier platform, device OS, MDM, or installed agent supports a reachable control channel.

What you can do:

Option A: Cellular iPad/iPhone
Use MDM + carrier IoT/eSIM APIs + Lost Mode + location.
Option B: Wi-Fi-only iPad
Use BLE/UWB/RFID exit detection before it leaves the building.
Once it leaves Wi-Fi, assume loss of command/control.
Option C: Add external tracker/modem
Use a rugged case with LTE-M/NB-IoT/GPS/BLE module.
That module reports independently from the iPad.
Option D: Badge-auth checkout model
Device must be associated with a user badge/session.
Unapproved exit creates security incident.

7. Best Enterprise Build Direction

For your idea, the strongest architecture is:

SignalGrid-style control layer
Inputs:
- MDM inventory/status
- Wi-Fi association
- BLE beacon proximity
- Door/access-control events
- Badge tap identity
- Carrier/eSIM status
- Location/geofence
- Device checkout state
- Shift/role/department
Decision:
- Approved movement
- Suspicious movement
- Lost/stolen
- Offline risk
- Exit violation
Outputs:
- ServiceNow incident
- PagerDuty alert
- Security desk notification
- MDM Lost Mode
- Play sound / lock app
- Disable session
- Badge/access escalation

The key product gap: Wi-Fi-only shared devices need pre-exit detection, not post-exit recovery. Cellular/eSIM gives post-exit visibility; BLE/UWB/RFID + badge/door integration gives pre-exit prevention.
