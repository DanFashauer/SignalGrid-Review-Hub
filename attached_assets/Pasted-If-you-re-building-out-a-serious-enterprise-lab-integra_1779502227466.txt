MDM / UEM / Endpoint Management

Open Source / GitOps / Endpoint Platforms

* FleetDM GitHub￼ — One of the strongest modern open-source endpoint management platforms built around osquery and GitOps workflows. Supports macOS, Windows, Linux, iOS, Android.  
* osquery GitHub￼ — Facebook/Meta-created endpoint telemetry and query engine used heavily in enterprise security.
* Santa GitHub￼ — Google’s macOS binary whitelisting/endpoint security framework.
* Kolide Launcher GitHub￼ — Endpoint telemetry/security tooling built around osquery.
* Micromdm GitHub￼ — Open-source Apple MDM server.
* NanoMDM GitHub￼ — Lightweight Apple MDM implementation.
* Munki GitHub￼ — Massive macOS enterprise software deployment ecosystem.
* AutoPkg GitHub￼ — macOS enterprise packaging automation.
* Installomator GitHub￼ — Enterprise macOS app deployment automation.
* MacAdmins Scripts GitHub￼ — Huge ecosystem of enterprise Apple management tooling.
