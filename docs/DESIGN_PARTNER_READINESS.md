# Design Partner Readiness

## Readiness criteria

- Executive one-pager reviewed.
- Demo script selected.
- Deterministic proof evidence shared.
- Public-safety guardrails accepted.
- Stage 3 sandbox requirements reviewed before any real environment discussion.
- Owner approves scope, audience, and follow-up actions.

## Dry-run agenda

1. Problem validation.
2. Public-safe demo walkthrough.
3. Proof evidence review.
4. Sandbox-readiness checklist review.
5. Decision: no-fit, later, deeper demo, or controlled sandbox scoping.
