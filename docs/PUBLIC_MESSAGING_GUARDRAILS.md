# Public Messaging Guardrails

Use these guardrails for social posts, profile copy, partner DMs, emails, one-pagers, and visual captions.

## Phrases to avoid publicly

Avoid these phrases unless a future owner-approved claim is separately validated and legally reviewed:

- production-ready
- certified
- compliant
- partnered with
- customer-proven
- replaces Intune
- replaces Jamf
- replaces MDM
- replaces IAM
- replaces ServiceNow
- replaces Imprivata
- autonomous production remediation
- live Microsoft Graph integration
- live Apple integration
- live PACS/locker integration
- HIPAA compliant
- SOC 2 certified
- MFi certified

## Safer alternatives

Use safer, pre-announcement language:

- exploring
- building
- prototype
- fixture-backed proof
- public-safe simulator
- candidate signal source
- future integration path
- systems of record remain external
- design-partner conversation
- pre-announcement
- category-building
- deterministic Review Hub proof
- private sandbox validation path

## Safe framing patterns

| Instead of | Say |
| --- | --- |
| "SignalGrid is production-ready." | "SignalGrid is in pre-announcement/category-building with public-safe fixture-backed proof." |
| "SignalGrid integrates with Microsoft Graph." | "SignalGrid has a fixture-backed Microsoft Graph sandbox proof and any live integration would require separate private validation." |
| "SignalGrid replaces MDM/IAM/ITSM." | "SignalGrid explores orchestration above systems of record; source systems remain external." |
| "SignalGrid is certified/compliant." | "SignalGrid is not presented as a compliance certification or attestation." |
| "SignalGrid performs autonomous remediation." | "High-risk actions remain simulated or approval-required." |
| "SignalGrid is partnered with X." | "X-like systems are candidate signal categories only unless a formal partnership is approved and public." |

## Pre-post checklist

Before publishing, confirm the copy:

- Frames SignalGrid as exploring or building, not launched or production-ready.
- Avoids customer, funding, acquisition, partnership, certification, compliance, valuation, and legal claims.
- Avoids real vendor logos unless discussing generic candidate categories without endorsement.
- Avoids customer data, tenant IDs, PHI, PII, screenshots from private systems, and live integration details.
- Keeps existing systems as systems of record.
- Asks for comparison notes or design-partner conversations rather than implying sales availability.

## Level 10 messaging guardrails addendum

Safe language includes public-safe review hub, deterministic proof evidence, fixture-backed scenarios, approval-gated recommendations, existing systems remain systems of record, and preparing for controlled sandbox/design-partner validation. Block production readiness, certification, endorsement, live customer deployment, autonomous production remediation, acquisition/investment outcome, revenue, valuation, legal terms, or replacement claims.
