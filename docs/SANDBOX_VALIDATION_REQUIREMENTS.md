# Sandbox Validation Requirements

Sandbox validation is a future private-context activity. This public repository may document requirements but must not include secrets, tenant IDs, real customer data, PHI/PII, live API calls, or production writes.

## Minimum requirements before Stage 3

- Owner approval for sandbox scope.
- Read-only first posture.
- Synthetic or explicitly approved sandbox-only data.
- No default write actions.
- Approval gates for any high-risk action.
- Evidence capture plan.
- Stop condition and rollback plan.
