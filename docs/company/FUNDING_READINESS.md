# Funding readiness — the recommendation the org owed the founder

Filed 2026-08-22 by the finance-fundraising lens, at the founder's direct
prompt — and with the miss owned first: this role existed in the roster for
weeks without producing the one recommendation a founder needs from it. Here
it is, honestly grounded in what the repository can prove. **Every path below
is a founder decision; nothing here self-executes.**

## What a funder or collaborator actually sees today (the asset inventory)

- **A readable company.** The entire product — engine, the proof-gate suite
  whose size `docs/STATUS.md` publishes and `check-status-figures.mjs` keeps
  true (this page cites it rather than keeping a second copy that can drift,
  the way its own hand-typed **136** did — the real figure was 140),
  audit ledger, threat model, release evidence with signed artifacts — is a
  public repository. For pre-seed diligence, this is rare: the diligence
  packet is `git clone`.
- **A ratified, narrow, provable claim** (POSITIONING.md): three signals,
  fail-closed, evidence per verdict — with a gate that fails CI on overclaim.
- **A live proof stack on open source** (DR-013): Fleet end-to-end, Keycloak
  15 dimensions, RADIUS/NAC, Traccar, Wazuh — no vendor spend.
- **Cost honesty** (COST_MODEL.md): limiter-bound serving, ≈$0 marginal
  tenant cost, one identified paid dependency, published denominators.
- **An operating system that runs itself**: the agent org, routines,
  decision records — a solo founder with a functioning team.
- **Not yet**: revenue, pilots, incorporation status on record, or any
  certification. Stated because a funder will state it first.

## The three paths, with a recommendation

### Path A — Pilot-first bootstrap (RECOMMENDED, and already running)
Land 1–2 shadow-mode pilots (the 30-day plan's engine, first sends Monday),
convert one to a paid design partnership. **Why first**: a paid pilot is
simultaneously revenue, the strongest possible funding evidence, and the
thing every other path prices off. Cost structure allows it — run-rate is
near-zero. **Risk**: founder time is the only burn, and the clock to
credibility runs through customer conversations either way.

### Path B — Pre-seed raise (angels / micro-VC), AFTER first pilot signals
$250–750k-shaped conversations become materially better the day one pilot
is running: the pitch shifts from "believe the repo" to "watch the pilot."
**Sequence, not skip**: prepare the material now (the repo + positioning +
pilot data become the deck), open conversations at first-pilot-live.
Founder-only actions: incorporation/cap-table hygiene, and the
conversations themselves — an agent can draft every document and research
every investor thesis, but a human raises money from humans.

### Path C — Non-dilutive / grant + open-source collaborator track (PARALLEL, cheap)
The open-source posture qualifies SignalGrid for paths most startups can't
touch: NSF SBIR-class small-business grants (US, non-dilutive, slow),
open-source security funds (Sovereign Tech, OpenSSF-adjacent — long shots
but zero-cost applications), and **collaborators**: the Fleet ecosystem
itself is a collaborator channel (a SignalGrid integration showcased to
Fleet's community reaches exactly our segment's practitioners). Cost:
agent-time to draft applications; founder-time only to sign and interview.

## Recommendation, in one line

**A now (running) + C's collaborator lane now (agent-executable) + B's
preparation now with conversations gated on first-pilot-live** — because
every path's terms improve monotonically with pilot evidence, and nothing
about preparing B or C delays A.
