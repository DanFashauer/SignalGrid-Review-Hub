How this works. Each situation is caught only when its workflow is active and the signals it needs are wired — then the grid evaluates it and returns allow / step-up / restrict / deny with the evidence behind it. It does not carry the response out: the host app acts, and any high-risk response is simulated or approval-required. Missing a workflow or a signal is a blind spot, and the fix is always to add. Each signal tag shows how it reaches the grid: via API or native when the source system integrates, or grid-collected when it doesn’t and the grid does the lifting itself — so the outcome depends on how your existing systems are configured (see docs/SIGNAL_SOURCING.md).
