# Target criteria — who we research, and why (the named list is private)

The named account list lives in the owner's private Google Drive — a public
repository is no place to name organizations that never asked to appear in
one. This page is the public half: the method, so the list is reproducible
and auditable in kind.

## The profile (DR-012)

75–1,000 employees · 1–10 IT staff · shared/frontline devices doing real
work · consolidation pressure (few tools, no security engineering team).
Never: Fortune-500 procurement, organizations requiring certifications we
do not hold, or anyone on the do-not-contact list.

## Segment quotas (40–60 accounts total)

| Segment | Quota | What qualifies |
| --- | --- | --- |
| Warehousing / 3PL / logistics | 12–18 | multi-site, shared scanners/station PCs, visible lean-IT hiring or stack |
| Clinics / outpatient / home health | 10–15 | shared carts/tablets, compliance pressure, no listed security team |
| Field service / facilities / utilities contractors | 8–12 | truck-and-depot fleets, handhelds |
| MSPs serving the above | 6–10 | 5–20 SMB clients, endpoint-management practice |
| Manufacturing / food processing | 4–8 | shared floor terminals |

## Research quality bar (each row in the private list carries)

Company · segment · size evidence (site/LinkedIn/job posts) · why-them (one
sentence naming their shared-device reality) · named role/person ONLY from
public professional sources · source links · date researched. A row missing
any of these does not get contacted.

## What we never do

Scraped or purchased lists; contacting personal addresses; researching
private individuals beyond their public professional role; keeping a row on
any request to be removed.
