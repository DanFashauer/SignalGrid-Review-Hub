## How to read this

Each framework concept carries one status:

- **proven** — a proof, gate or test exercises it; the evidence column names the files.
- **doctrine-only** — documents describe it; no gate holds it. A claim, not a control.
- **absent-relevant** — missing, and plausibly in scope for a shared-device decision grid.
- **out-of-scope** — missing on purpose; the note says why the boundary is drawn there.

Every evidence path is checked by `check:cited-paths` on each run, so a file that moves or
dies fails the build rather than leaving a phantom citation. The one-line notes are the
sweep's summaries; the linked files are the truth. Statuses are the 2026-08-31 sweep's
judgement of what a gate holds — not a certification of anything beyond that.
