## G. Builder/proof post

### Polished public copy

Before claiming integration, prove the decision model with deterministic fixtures.

That is the discipline behind the SignalGrid Review Hub.

The public proof should not need credentials, tenant IDs, customer data, PHI, PII, live Microsoft Graph calls, live Apple integrations, or vendor API access to explain the decision model.

First, prove the shape:

- What signal came in?
- What context changed?
- What decision was made?
- Was approval required?
- Who owns the route?
- What evidence was recorded?
- What result should be verified?

Only after that should a private sandbox path be considered.
