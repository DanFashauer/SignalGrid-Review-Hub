# Strategic Options Decision Tree

Start: Is the conversation primarily about learning, distribution, capital, embedded product fit, or ownership transfer?

- **Learning** → Design partner path → public-safe demo → dry-run checklist → possible sandbox scoping.
- **Distribution** → Strategic partner path → category fit → co-demo concept → no endorsement claim unless formally approved outside this repo.
- **Capital** → Strategic investment path → founder-control discussion → no valuation or legal terms in public materials.
- **Embedded product fit** → OEM/embedded path → fixture-backed integration concept → private technical diligence only after approval.
- **Ownership transfer** → Acquisition path → retained product leadership preference → full buyout only as last option.

This document is a planning aid, not legal or financial advice.
