# Connector emulator fixtures

These JSON files are synthetic, public-safe connector scenario packs for the cloud connector emulator harness. They contain no secrets, tenant IDs, customer records, PHI, PII, live auth material, or live vendor API endpoints.

The fixtures validate Graph/Intune-shaped posture, IAM/IGA-shaped identity governance, MDM/MAM app and device posture, workflow routing, physical custody, network trust, and security/EDR-style risk semantics without claiming live integration evidence.
