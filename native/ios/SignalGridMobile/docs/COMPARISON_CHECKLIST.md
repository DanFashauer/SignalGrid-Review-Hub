# Comparison checklist

Use this when comparing the native build to the current web/PWA implementation.

## Product behavior

- [ ] Four authoritative outcomes render distinctly.
- [ ] Missing or degraded critical evidence never becomes a plain allow.
- [ ] Every result includes reason codes and policy version.
- [ ] Decision detail shows evidence snapshot and normalized signals.
- [ ] Connector state is read-only and clearly fixture-backed.
- [ ] Sessions can start, refresh, and end.
- [ ] Sensitive host-app actions never auto-run.
- [ ] Step-up uses a native device authentication prompt.
- [ ] Frontline app copy does not expose SignalGrid branding.
- [ ] Operator surfaces remain clearly separated from worker surfaces.

## UX comparison

- [ ] Operator overview tells the product story in under one minute.
- [ ] Trust Lab makes scenarios easy to compare.
- [ ] Decision history is readable on iPhone and iPad.
- [ ] Evidence is detailed without overwhelming the primary result.
- [ ] Systems view presents connectors, policies, and audit clearly.
- [ ] Settings makes demo/live mode explicit.
- [ ] Wardlink feels like a host application, not a security console.

## Safety comparison

- [ ] Demo mode contains no secrets or customer identifiers.
- [ ] No production-readiness, certification, partnership, or replacement claims appear.
- [ ] Demo step-up fallback is labeled as simulation.
- [ ] No remediation or vendor write action is performed.
