# Public lane regression fixtures

These checks exercise disposable local repositories, local Git hooks, the current
delivery source, the actual Bash FD8 guard and real filesystem descriptors. GitHub
responses and unrelated schema gates are explicit local seams. They make no live
GitHub, provider or model request and establish no native coding or delivery claim.

Run `node scripts/check-lane-push.mjs` for31 preserved push-result and strict-refusal
**unit** controls, `node scripts/check-lane-mismatch.mjs` for four complete-heartbeat
wrong-witness integration controls, and `node scripts/check-lane-lease-tree.mjs`
for the preserved five filesystem snapshot controls. Each is registered in full
preflight and CI.

The strict-refusal unit fixture substitutes only the independent generic HOLD
notification dependency with a recorded callback. The actual refusal validator,
FD8 ownership and refusal publication path remain real and source-identical.
No operation counter is filtered. A wrong witness must reach exactly one recorded
HOLD callback while the original zero-hand assertions still apply to that unit.
This cohort alone is not complete-heartbeat coverage. The four separate integration
cases use the unmodified generic HOLD function and actual current repair module;
they count every emitted operation and require exactly one same-original-ID,
hash-only uncertainty notice with no false source-bound refusal/absence claim,
private payload or original replay. Original test methods/assertions remain intact;
this explicit dependency split distinguishes strict witness rejection from the
separately authorized uncertainty signal.

The tests originated as operator-created frozen regressions for this repository.
All original assertion statements remain in their public ports; setup now uses the
current repository root, the invoking Node executable and owned disposable files.
The raw-capture adapter retains the independently observed local Git bytes and
does not fabricate accepted production evidence. Private runtime/history tests
belong to a separate component and are outside these public cohorts.

The repository's MIT license covers this source. No third-party source, library,
private receipt, vault note, account data or runtime configuration is copied here.
On macOS the wrapper inherits the operating system's `sandbox-exec` network-deny
profile. On Linux it uses the operating system's existing `libseccomp.so.2` API
through Python's standard `ctypes` module. The unchanged real socket/connect
assertion must establish `EPERM` or `EACCES`; unavailable enforcement fails the
check without installation, fallback or skip. This bounds network transport for
these fixture processes and their descendants; it is not a provider or generic
runtime containment qualification.

The actual `HOME` value is preserved. Fixture Git configuration is isolated, all
remote Git targets are owned local bare repositories, and GitHub URLs are inert
`fixture/route` labels consumed by local shims. There is no timeout or forced
cleanup. Original child output and terminals are retained before interpretation;
failures retain their unique fixture directory. Only a normal successful complete
suite permits its wrapper to remove that same owned disposable tree.
